# 现在就出发

个人旅行首页，使用原生 HTML、CSS 与 JavaScript，无需安装依赖或构建。

## 本地预览

在项目目录执行 `python3 -m http.server 8000`，访问 `http://localhost:8000`。

## 内容与功能

- 2026.09.25 至 2026.10.05 的旅行摘要：11 天、2 个国家、5 个目的地。
- 米兰、多洛米蒂、佛罗伦萨、罗马、巴黎的路线、实拍相册及旅行手记。
- 照片详情弹窗，支持键盘、Escape 关闭、点击背景关闭和焦点返回。
- 响应式布局；跟随系统配色，也可手动切换并记住选择；尊重减少动态效果偏好。
- 首页底部居中显示 `浙ICP备2026088446号-1`，链接至 `https://beian.mps.gov.cn/#/query/webSearch`。

照片来自站点所有者的旅行记录，已缩放压缩并移除 EXIF。照片及个人旅行文字的权利归原作者所有。11 天按 9 月 25 日至 10 月 5 日含首尾日期计算，目的地按五个主要停留地统计；不包含返程到国内的时间。

## 修改与部署

入口为 `index.html`，样式在 `styles.css`，相册内容和交互在 `script.js`，图片在 `assets/`。将这些文件及 `favicon.svg` 一同上传至静态网站主机即可，支持根目录或子目录部署，不依赖外部 CDN。
